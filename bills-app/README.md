# 🧾 فواتيري — لوحة متابعة فواتير الكهرباء والمياه والغاز

موقع بسيط (Next.js) بيجيب حالة فواتيرك التلاتة في صفحة واحدة:

| المرافق | الشركة | الحالة |
| --- | --- | --- |
| ⚡ الكهرباء | شركة الاسكندرية لتوزيع الكهرباء | ✅ **مُختبَر وشغال** — اتجرب على الصفحات الحقيقية بتاريخ 20 نوفمبر 2026 |
| 💧 المياه | شركة مياه الشرب بالإسكندرية | ⚠️ **غير مُختبَر** — الموقع محجوب من بره مصر، اتكتب من نسخة مؤرشفة |
| 🔥 الغاز | بتروتريد Petrotrade | ⚠️ **غير مُختبَر** — الموقع محجوب من بره مصر، اتكتب من نسخة مؤرشفة |

---

## 🚀 النشر على Vercel

### الطريقة الأولى: من GitHub (الأسهل على المدى الطويل)

1. اعمل ريبو جديد على GitHub وارفع عليه الملفات دي كلها
2. افتح [vercel.com](https://vercel.com) وسجل دخول
3. **Add New → Project** واختار الريبو
4. دوس **Deploy** — مش محتاج تغيير أي إعدادات

### الطريقة التانية: من التيرمنال مباشرة

```bash
npm i -g vercel
cd bills-app
vercel
```

## 💻 التشغيل على جهازك (محلي)

```bash
npm install
npm run dev
```

وافتح `http://localhost:3000`

> **مهم:** التشغيل المحلي من مصر هو أضمن طريقة للمياه والغاز، لأن مواقعهم
> محجوبة من أي سيرفر بره مصر (ومنها سيرفرات Vercel غالبًا).

## 🔢 تغيير أرقام الحسابات

الأرقام موجودة في ملف واحد: **`lib/config.mjs`**

| الرقم | المتغير | القيمة الحالية |
| --- | --- | --- |
| الكهرباء (الرقم الآلي) | `ELEC_REFERENCE_ID` | `8420808023306011` |
| المياه (رقم السداد/الحساب) | `WATER_ACCOUNT` | `17020000580634` |
| الغاز (رقم المشترك) | `GAS_SUBSCRIPTION` | `0309191905120700` |

إما تعدّل الملف مباشرة، أو تحط القيم في Vercel من
**Project Settings → Environment Variables** (لها الأولوية على الملف).

## ⚠️ تحذيرات مهمة

1. **المياه والغاز من جوه مصر بس:** موقع `alexwater.com.eg` وموقع
   `petrotrade.com.eg` بيرفضوا الاتصال من أي IP بره مصر. لو نشرت على Vercel
   (سيرفرات أوروبا/أمريكا) الكارتين دول هيطلعوا رسالة خطأ واضحة. الحلول:
   - شغّل الموقع محليًا على جهازك (`npm run dev`)
   - أو انشره على استضافة جوه مصر

2. **الكهرباء ورا Cloudflare:** موقع `alex.ahram.org.eg` أحيانًا بيطلب تحقق
   أمني من السيرفرات. لو حصل ده هتظهر رسالة توضح إنك تجرب تاني أو تشغّل من
   شبكة مصرية. من التجربة: الطلبات العادية من شبكات كتير بتعدي من غير مشاكل.

3. **التحليل ممكن يبوظ لو المواقع غيّرت شكلها:** الكود بيقرأ شكل الصفحات
   الحالي. لو شركة غيّرت موقعها، الكارت هيطلع خطأ `PARSE_ERROR` — راجع
   التعليقات في `lib/electricity.mjs` أو `lib/water.mjs` أو `lib/gas.mjs`.

## 🔧 إزاي بيشتغل؟

- **الكهرباء:** بيجيب صفحتين: `PreviousConsumption` (الاسم + تاريخ الاستهلاك)
  و`InvoiceDetails` (الشهر، الاستهلاك، إجمالي الفاتورة، حالة السداد).
- **المياه:** بيبعت رقم السداد POST لـ `fatora_awco2.php` ويقرأ الرد.
- **الغاز:** ASP.NET WebForms — بيجيب الصفحة الأول (عشان الحقول المخفية
  `__VIEWSTATE` وغيرها)، وبعدين بيبعت رقم المشترك متقسم على 8 خانات
  (`T1..T8`) مع زرار "اعرض".

لو المياه أو الغاز طلعوا أرقام غلط بعد ما تجرب من مصر، ابعت لقطة شاشة من
نتيجة الموقع الرسمي والتحليل يتظبط بسهولة.
